Deriving Scientific Credit, Lab Memory, and Citable Artifacts from Daily Research

Modern scientific collaboration is scattered across Discord channels, GitHub repositories, Google Docs comments, meeting transcripts, and LLM drafting sessions. This infrastructure captures the daily collaboration footprint, normalizes it into a W3C PROV-O provenance graph, and routes it dynamically to local lab RAG, federated consortium feeds, or citable Zenodo DOIs.

Decoupled Architecture

Four Ways Lab Footprints Are Reused

Answering "Why a DOI for everything?": Different organizations require different publishing postures. Process as Provenance decouples data collection from public exposure.

Tier 1: Internal

Private Lab RAG

Ingests daily chat logs, Jupyter outputs, and code commits into a local vector database. Powers Ollama/Claude drafting sessions with zero external data exposure.

Ideal for: Stanford bench testbeds, private lab onboarding, IP-sensitive projects.
Tier 2: Peer-to-Peer

Federated Aggregators

Syndicates structured progress summaries across institutions using P2P feed architectures like Stephen Downes' CList. Enables collaborative reading, annotating, and gap analysis.

Ideal for: Multi-university consortia (UK NeuroSync, NSSP Lab, ONM).
Tier 3: Discovery

Funder & Lab Matching

Publishes scrubbed, high-level capability digests. Program managers identify active research capacity in real-time, moving beyond multi-month RFP cycles.

Ideal for: NSF POSE, NIH BRAIN, Sloan Foundation, DARPA sprints.
Tier 4: Citable

Public RO-Crate DOIs

Reserved for finalized protocols, verified benchmark suites, and accepted papers. Gated by human editorial review, packaged into RO-Crate 1.1 with DataCite DOIs.

Ideal for: Published methods, citable datasets, negative results repositories.

Everyday Researcher Workbench

Four core modules that streamline everyday scientific collaboration across local, federated, and open spaces.

Token-Budgeted Context Bundles for LLMs

Extracts active discussion threads, accepted design decisions, and active code references into compact markdown context packages (~500 tokens). Injected into Claude, GPT-4, or local Ollama instances to eliminate hallucinations when drafting manuscripts or code.

Outputs: Compact CLI, Web Copy, API System Prompt Ingestion

Zero-Loss Institutional Lab Memory

Preserves chronological decision histories across graduate student and postdoc transitions. New lab members onboard in hours by browsing structured decision trees and context bundles rather than digging through dead chat logs.

Outputs: Milestone Logs, Decision Records, Onboarding Diffs

1-Click Progress & Funder Reporting

Compiles annual progress reports for funding agencies, grant milestones, or institutional reviews. Generates formatted LaTeX and PDF summaries documenting collaborative activity, software releases, and student training records.

Outputs: Progress Reports, LaTeX Briefs, Metric Summaries

FAIR Research Object Packaging

Automatically packages code repositories, discussion transcripts, and benchmark datasets into standardized RO-Crate archives deposited directly to Zenodo for persistent DOI citation in published manuscripts.

Outputs: Zenodo RO-Crate .zip, JSON-LD Graph, Summary PDF
