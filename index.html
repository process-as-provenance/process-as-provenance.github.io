Neuroscience Workbench

Coordinates experimental neuroscience test suites, benchmark workflows, and multi-contributor computational projects. Preserves institutional memory across student and researcher transitions, grounds local/cloud LLMs in active research context, and automates progress reporting. The goal is to meet researchers where they already work, not to eliminate every new step — milestone tagging and review sign-offs remain a modest, deliberate ask, and anything that happens purely over email or in an off-the-record call stays outside the system unless someone routes it in.

Infrastructure

Everyday Researcher Workbench

Four core modules that streamline everyday scientific collaboration. The aim is to meet researchers where they already work — Discord, GitHub, docs — rather than invent a new one; it can't capture what happens purely over email or an off-the-record call, and milestone tagging still asks for a few minutes of deliberate human review.

Token-Budgeted Context Bundles for LLMs

Extracts active discussion threads, accepted design decisions, and active code references into compact markdown context packages (~500 tokens). Injected into Claude, GPT-4, or local Ollama instances to eliminate hallucinations when drafting manuscripts or code.

Outputs: Compact CLI, Web Copy, API System Prompt Ingestion

Zero-Loss Institutional Lab Memory

Preserves chronological decision histories across graduate student and postdoc transitions. New lab members onboard in hours by browsing structured decision trees and context bundles rather than digging through dead chat logs.

Outputs: Milestone Logs, Decision Records, Onboarding Diffs

1-Click Progress & Milestone Reporting

Compiles annual progress reports for funding agencies, grant milestones, or institutional reviews. Generates formatted LaTeX and PDF summaries documenting collaborative activity, software releases, and student training records.

Outputs: Progress Reports, LaTeX Briefs, Metric Summaries

FAIR Research Object Packaging

Automatically packages code repositories, discussion transcripts, and benchmark datasets into standardized RO-Crate archives deposited directly to Zenodo for persistent DOI citation in published manuscripts.

Outputs: Zenodo RO-Crate .zip, JSON-LD Graph, Summary PDF
Foundations

Standards & Vocabularies

Built entirely on open W3C, ANSI/NISO, and CERN-backed standards to guarantee persistent, non-proprietary scholarly outputs.

W3C Recommendation Provenance

W3C PROV-O

Encodes how research entities (prov:Entity) are generated by activities (prov:Activity) and attributed to human/software agents (prov:Agent).

Status: Core Semantic Model W3C Spec
Packaging Standard Packaging

RO-Crate 1.1

Community-driven standard for packaging research datasets, code diffs, transcripts, and metadata into a self-describing archive based on JSON-LD and Schema.org.

Status: Export Target RO Spec
ANSI / NISO Standard Attribution

NISO CRediT Taxonomy

ANSI/NISO Z39.104-2022 standard defining 14 contributor roles (e.g., Conceptualization, Software, Methodology, Writing) to replace coarse author order debates with transparent matrices.

Status: Contributor Tagging Taxonomy
Open Repository Packaging

Zenodo & DataCite DOIs

CERN-backed open scientific repository providing persistent DOIs for collaboration bundles, code, and datasets for direct citation in academic manuscripts.

Status: Deposition Target Repository
Academic Ontology Provenance

PAV Ontology

Provenance, Authoring, and Versioning extension distinguishing accountable human authorship (pav:authoredBy) from generative software tooling (pav:createdWith).

Status: Semantic Layer Ontology
Validation Language Attribution

W3C SHACL

Shapes Constraint Language enforcing structural graph integrity rules (such as validating that every public communicative act is bound to a verified human accountable author).

Status: Graph Validator W3C Spec
